PROFESSIONAL DELIVERY FRAMEWORK FOR MAILA CHIC

The following Maila Chic brief defines the product: a French-language V1 showcase announcing upcoming online sales, followed by a commerce-enabled V2 using APIs.

This framework defines the working method and quality standard. Apply it to the entire brief.

EXPECTED RESULT

Deliver a website that could be presented to a fashion brand as the finished work of a design and engineering team.

The visual identity must be specific to Maila Chic. Express contemporary elegance, the relationship between materials, and appreciation for craftsmanship through deliberate composition and credible content.

Complete the entire V1 scope. A polished homepage is insufficient if secondary pages, forms, and mobile layouts are unfinished.

CAPABILITIES AND TOOLS

First identify the capabilities actually available:
- Specialised agents.
- Design and development skills.
- Plugins.
- Browser inspection tools.
- Screenshot and visual review tools.
- Existing project libraries and components.

Use relevant capabilities when they materially improve the result.

Do not assume a tool exists. Do not claim agent collaboration, skill usage, or visual verification that did not occur.

Do not block delivery because an optional plugin is unavailable. Adapt the workflow and disclose limitations that materially affect delivery.

Avoid adding dependencies for simple functionality.

MULTI-AGENT ORGANISATION

If multiple agents are available, establish explicit responsibilities:

1. Art direction and user experience
   Define composition, proportions, typography, photography treatment, and the prelaunch journey.

2. Content and information structure
   Adapt the Maila Chic narrative, organise pages, and identify claims requiring confirmation.

3. Implementation
   Build components, pages, structured data, and authorised integrations.

4. Independent review
   Review the implemented pages, journeys, accessibility, mobile layouts, and consistency with the chosen direction.

An integration lead must retain responsibility for the overall result and resolve disagreements. Deliver one coherent visual system and navigation model.

Assign file ownership before parallel modifications to prevent editing conflicts.

If agents are unavailable, perform these roles sequentially. Keep the same quality standard.

ART DIRECTION BEFORE FULL IMPLEMENTATION

Define a coherent design direction before building every page:
- Palette and colour roles.
- Font families and rationale.
- Heading and body type scale.
- Content widths.
- Spacing rules.
- Desktop and mobile grids.
- Image aspect ratios and cropping rules.
- Button, link, and field styles.
- Textile-inspired accents.
- Interactive states.

Briefly explain how these decisions support Maila Chic.

Treat the attached mockup as an atmosphere reference. Adapt it to prelaunch, improve readability and pacing, and design its mobile interpretation.

Do not mechanically reproduce every reference element.

COMPOSITION AND IDENTITY

Use an editorial composition:
- A readable hero with a strong image.
- Clear hierarchy between discovery, storytelling, and signup.
- Deliberate variation between sections.
- Breathing room.
- Precise alignment.
- Content density appropriate to each screen.

Graphic details must have a brand-related purpose.

Avoid unjustified visual defaults:
- Pervasive gradients.
- Glass effects.
- Rounded cards around every content block.
- Repeated shadows.
- Excessive badges.
- Generic icons replacing useful information.
- Animation on every element.
- Identical sections stacked without pacing.

Use these treatments selectively when they serve a clear intention. They must not substitute for a brand identity.

TYPOGRAPHY AND COPY

Use a small number of type families with consistent roles.

Check:
- Line length.
- Line height.
- Heading wraps.
- Heading-to-paragraph spacing.
- Small text readability.
- French accented characters.
- Desktop and mobile consistency.

Write restrained, precise, warm French copy.

Avoid interchangeable slogans, constant superlatives, and repetitive paragraphs.

Do not replace missing facts with invented marketing claims.

PHOTOGRAPHY AND ASSETS

Photography is central to the result.

Inventory available assets and distinguish:
- Real, authorised photographs.
- Reference material.
- Temporary visuals.
- Missing images.

Define the required image type, aspect ratio, and crop for each placement.

Preserve important product and material details. Avoid cropping handles, finishes, or essential features.

Do not use generic artisan photographs to imply a real partnership.

If assets are insufficient, create a carefully composed temporary layout and document replacements required before publication.

COMPONENTS AND INTERACTIONS

Adapt components to the art direction instead of retaining a library's default appearance.

Refine:
- Hover states.
- Keyboard focus.
- Disabled states.
- Errors.
- Confirmations.
- Loading states.
- Mobile menus.
- Empty pages and sections.

Every action must have a real destination or behaviour.

Keep the primary journey simple:
discover the brand, explore documented collections, understand the upcoming launch, and request an alert when the service is operational.

MOBILE QUALITY

Design mobile as a deliberate composition.

Check:
- Hero image and message placement.
- Thumb-friendly navigation.
- Interactive target sizes.
- Heading wraps.
- Form readability.
- Page length.
- Image cropping.
- Overflow.
- Longer text handling.

Do not simply shrink the desktop grid.

VISUAL REVIEW PROCESS

When browser and screenshot tools are available:
1. Run the website.
2. Inspect the homepage and secondary pages.
3. Review several widths, including a small phone, a typical phone, a tablet, and a desktop.
4. Inspect menus and form states.
5. Identify composition and interaction defects.
6. Correct priority defects.
7. Recheck modified areas.

Evaluate the rendered website, not just the source code.

If visual review is unavailable, state that limitation. Do not claim verified visual polish.

FINISHING CRITERIA

Before completion, check:
- Consistent spacing.
- Block alignment.
- Colour and component consistency.
- Image quality.
- Heading hierarchy.
- Absence of filler content.
- Absence of fake contact details.
- Absence of nonfunctional buttons.
- Honest form states.
- Consistency across all pages.
- Mobile readability and comfort.
- Absence of a purchase journey in V1.

Fix defects that make the website visibly unfinished.

SCOPE AND ACCURACY

V1 introduces the brand and prepares its launch. It does not sell.

Do not add carts, payments, simulated orders, invented reviews, or unconfirmed commercial promises to make the site appear complete.

Preparing V2 means structuring data and interfaces appropriately. It does not mean implementing the entire store immediately.

All public content remains in French regardless of the language used for technical work.

DELIVERY

Deliver the implemented authorised scope and a concise report covering:
- Selected art direction.
- Completed pages and functionality.
- Checks actually performed.
- Remaining defects and limitations.
- Assets and information required before publication.
- Steps for the V2 transition.

The final standard is a coherent, credible website with carefully finished details, not the number of agents, plugins, or lines of code used.

Do not use long dash characters in content, comments, or documentation.
